# 2026-11-14 — GPT-6.1 terra vs sol on Hermes

Both models through the Hermes bridge (ChatGPT Plus subscription), default effort of each route (`low`),
dev database, `feat/eval-model-bench`. Shop bot: 126 cases × 2 runs. Owner assistant: 12 cases × 3 runs.

The first sol shop run hit the ChatGPT 5-hour usage limit (HTTP 429): 17 cases errored and were rerun with
`--id` after the reset. The sol shop numbers below combine both runs. The assistant suites ran again,
one model after the other.

terra failures (real behaviour, half the runs):

- `hotel-a17-weekend-free-from-calendar`: asked for the children's ages instead of checking availability.
- `hotel-a17-zero-inventory-is-not-sold-out`: asked for dates and guests instead of saying the calendar has
  no schedule.
- `tinymind-several-products-own-pictures`: sent the pictures but shortened the product name in the text.

sol failures (every run, both about wording):

- `retail-refund-complaint-hands-off`: hands off correctly and says "em rất tiếc", but never "xin lỗi".
- `spa-request-status-no-handoff`: the reply is right ("đang chờ nhân viên liên hệ xác nhận … Em chưa có
  thông tin lịch đã được xác nhận"); the forbidden pattern `đã được xác nhận` does not see the negation
  "chưa có thông tin". A grader false positive.

## Reading

- Under rule 1 of the README neither model is eligible: both fail critical shop cases.
- sol makes fewer behaviour mistakes: its two failures are wording, one of them the grader's. terra skips
  the availability check on the villa calendar in half the runs, which is the money path for lodging.
- terra is faster (P95 shop 9.4 s vs 12.9 s, assistant 21.6 s vs 31.8 s) and uses about half the input
  tokens per call, so it would cost about half on the production API.
- gpt-6-luna (the current route) last scored 124/126 shop and 12/12 assistant on a single run, which is
  not comparable with these repeated runs.

Recommendation: keep `gpt-6-luna` on the routes for now. If a 6.1 model is wanted, take sol for the shop
bot (behaviour) after fixing the `spa-request-status-no-handoff` pattern, and terra for the owner
assistant (same score, faster, cheaper). Before switching, rerun luna with `--repeat 2` / `--repeat 3` so
the three models are compared on the same footing.
